# 点数指定を目標描画時間と保持率の自動調整に置き換える

`data.visiblePointLimit` を廃止し、`gpu.targetRenderTimeMs` で点の絞り込みと GPU 描画に掛ける時間の目標を指定する。既定値は 8 ms とする。端末・解像度・表示領域・点サイズの違いを固定の点数指定で吸収する代わりに、計測時間から LOD の保持率を調整する。CPU のラベル描画、初期読み込み、ブラシ選択は計測対象に含めず、時間目標や FPS の達成を保証しない。

対応環境では `timestamp-query` で最初の compute から最後の描画までを測る。非対応時や読み戻し失敗後は、キュー完了までの粗い経過時間を使い、診断表示でも方式を区別する。保持率は連続値で計測差を追わず、決まった段階を最低 500 ms の間隔で選ぶ。減らす条件と増やす条件に余裕を設け、同じ段階の往復を抑える。パン・ズーム中は保持率を固定し、停止から 200 ms 後に計測を再開する。時間目標への細かな追従より、操作中に点が出入りしないことを優先する。

軽い描画だけのフレームは保持率調整に使わず、絞り込みを含む計測を基準にする。全点走査などの固定負荷で目標を達成できない場合も、保持率の下限で停止する。

利用者の操作が止まった後も有限回の再描画で再調整する。常時描画のループは作らず、データ・解像度・目標時間の変更前の計測や、別の保持率の計測を後から適用しない。描画点の選び方は [ADR-0004](0004-overview-size-priority.md) のサイズ境界と同サイズのハッシュ間引きを維持する。

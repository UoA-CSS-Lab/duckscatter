# ポインターのホバーは描画点、ID 指定は全点を対象とする

ポインターによるホバーは、LOD と表示範囲を通過して点本体が描画される点を対象とする。`grayed` で描画されるフィルター不一致点も含める。見えている点を調べる操作として一貫させるため、フィルター一致だけを基準にする現行の空間検索から変更する。

一方、`setPointHover(id)` は全点集合から対象を指定する操作として維持する。LOD やフィルターから外れた点も別レイヤーのアウトラインで示せるが、点本体の描画集合は変更しない。

## 現行実装との差分

この方針は未実装。現在のポインター検索はフィルター一致を要求するため灰色の不一致点を対象にせず、LOD を見ないため非描画点を対象にする。ID 指定は既に全点を対象にできる。実装では、点本体の一致・不一致の両描画集合とホバー候補を一致させる必要がある。

現在のアウトライン描画には、ラベルが存在し表示されていることへの依存がある。ラベルが 0 件または非表示の場合も対象指定と注目の表示を扱えるよう、この依存の解消を合わせて検討する。明示的にアウトラインを無効にした設定は尊重する。

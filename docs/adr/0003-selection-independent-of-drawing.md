# 選択集合をフィルターと描画点から独立させる

選択は全点集合に対して保持し、フィルター、表示範囲、LOD が変わっても選択集合そのものは変更しない。画面に描画された点だけを選択とみなす方式よりも、探索中に表示条件を変えても利用者の選択を維持できることを優先する。

選択は GPU の 1 bit/point マスクで保持し、描画経路で CPU への読み戻しを挟まない。件数が必要な場合だけ非同期に取得するコストを受け入れる（実装時の判断: `8b6daa0`）。`getSelectionCount()` は全選択数であり、条件に一致する選択数や描画された選択数ではない。後二者を直接返す専用 API は現在提供していない。

選択やホバー強調は点本体の LOD・フィルター・表示範囲の判定を迂回しない。強制描画で選択を示す方式に比べ、描画予算と表示条件の意味を保つことを優先し、選択結果の件数や一覧は利用側で補う。単一点ホバーのアウトラインは点本体とは別の表示として扱う。

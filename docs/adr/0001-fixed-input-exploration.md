# 座標計算済みの固定データを探索対象とする

duckscatter は特定のアプリに依存しない、座標計算済みの点群をブラウザ内で探索するライブラリとする。座標計算、クラスタリング、ラベル生成は利用側の責務とし、初期化前の準備を終えた時点で行集合と座標を固定する。前処理や行の追加・削除まで取り込む方式に比べ、点の対応関係と表示・選択の責務を明確にできることを優先する。

初期化時の派生列・座標の準備、表示中のパン・ズーム、フィルター、色・サイズの変更は扱うが、行集合や座標の差し替えでは散布図を作り直す。対象規模は数十万〜数百万点を想定し、性能の対応範囲は実測で確認する。

点 ID はその散布図に読み込んだ行を識別する内部 ID とし、`rowid` とバッファ添字の対応を維持する。業務 ID や再読込をまたぐ永続 ID の管理は利用側に置く。
